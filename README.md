# Автоматизированное рабочее место библиотекаря

**Автоматизированное рабочее место библиотекаря (АРМ)** предназначено для автоматизации ключевых процессов работы библиотекаря. Система позволяет эффективно управлять библиотечным фондом, работать с читателями и контролировать выдачу книг.

## Основные возможности

Программа реализует следующие функции:

- **Управление каталогом библиотечного фонда**  
- **Ведение читательских карточек**  
- **Поиск книг и читателей в базе данных**  
- **Оформление выдачи и списания книг**  
- **Списание книг из фонда** 
- **Формирование извещений о задолженности**  


Для разработки использовались:

- **WPF** — для создания интерфейса приложения.  
- **SQL Server (SSMS)** — для локального развертывания базы данных.  

> ⚠️ Так как база данных развертывается локально, строка подключения может отличаться в зависимости от вашей системы.

## Настройка подключения к базе данных

В проекте файл **`...\АРМ Библиотекаря\Classes\BasicFunction.cs`** содержит строку подключения:

```csharp
SqlConnection sqlConnection = new SqlConnection(
    "server=(localdb)\\MSSQLLocalDB;Trusted_Connection=Yes; DataBase=Librarian_Workplace; TransparentNetworkIPResolution=False; Connect Timeout=30; Max Pool Size=400"
);
```
У меня сервер указан как (localdb)\MSSQLLocalDB. У Вас он может отличаться, поэтому обязательно проверьте через SSMS перед запуском приложения.
Использование Microsoft Azure для развертывания базы данных не применялось, так как бесплатные услуги больше не предоставляются и существуют ограничения для пользователей из России.
